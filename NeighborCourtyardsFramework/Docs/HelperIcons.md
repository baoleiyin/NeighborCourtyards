以下为可复建设计说明，并非工具原始提示词的逐字存档：

制作 4 列 × 3 行、等尺寸格子的游戏管理 UI 图标图集。透明背景，所有图标居中，保留透明边距。暖纸色、奶油、琥珀和鼠尾草绿，深棕轮廓，简化细节，适合 30–44 像素显示，无文字和格线。主题从左到右、从上到下：小屋总览、两个邻居头像、工作工具、营地旗；图鉴书本、清洁扫帚、搬运木箱、餐碗；月亮与枕头、叶片盾牌、定位标记、提醒铃铛。

程序以枚举顺序裁切，不单独依赖每个图标文件。主导航保留文字，不能仅凭颜色或微小细节区分功能。当前主导航使用前五格；其余格供通用动作按钮使用。
