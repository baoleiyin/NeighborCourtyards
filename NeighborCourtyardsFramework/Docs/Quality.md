# 核心测试记录（0.7.0-dev.1）

记录核心 `0.7.0-dev.1` 的接口、构建、模板和存档兼容测试。

这是原开发版本的历史验证记录。下文的运行目录、日志、截图和基线二进制未随 Git 仓库提供；本仓库保留[验证脚本](../Validation/Run-Checks.ps1)及摘要 JSON，重新运行命令见本页后文。组合仓库另有 `Docs/Testing.md` 教程。

## 基线

采用 2026 年 11 月 1 日正式发布的核心 0.6.9。整理前，分别编译原有核心与家庭源码，再与发布 DLL 的反编译结果逐项比较，两份文本差异均为零。比对文件保存在本地 `Validation/Baseline`。

公开 API 对比检查程序集身份、类型与继承、方法参数名称和签名、字段与常量、属性及事件。目前保留基线的 745 项声明，详情见 `Validation/api-comparison.json`。

## 已修复与整理

- 配置检查覆盖空列表及空条目、无效 Def 引用、重复岗位和工作条目、无穷与 NaN 数值、非法适配器类型及餐食数量溢出。
- 助手与迎新组件验证其宿主、种族关联与 ticking 配置，错误更早出现在对应定义的加载检查中。
- 外观回调异常时清理尚未交回迎新列表的角色，失败迎新统一清理角色、床位与行走记录。
- 迎新增加同迎新点的重入保护。完成回调在提交之后调用，回调异常记录到日志，保留已经完成的入住。
- 成人与儿童生成阶段由迎新成员身份明确传入。儿童年龄支持配置，父母年龄下限受种族最大年龄约束。
- 迎新时间推进使用宽整数运算，处理 `int.MaxValue` 这类大步长。运行时无效半径在设置写入前被拒绝。
- 名字池支持按池选择多语言名称，旧配置默认采用双汉字规则，多语言名称参与现有重名检查。
- 幼体图集检查帧范围与有限正数高度。
- 编译依赖通过参数提供，启用警告视为错误，保存源码与输出哈希，并在两个程序集编译成功后写出结果。
- 提供纯 XML 模板、命名与前缀替换脚本、公开适配器示例、接入文档及 MIT 代码许可。

## 验证方式

自动运行环境为本机 RimWorld 1.7 Waylith/.NET 平铺运行时。每次运行使用独立游戏目录、模组快照及保存目录。

`FrameworkProbe.cs` 覆盖两个独立种族的注册、配置错误、迎新前后异常、回调重入、床位与餐食状态、家庭年龄、正常工作 AI、入床、姓名、工作策略与存档重载。

`LegacyProbe.cs` 先使用正式 0.6.9 核心和现有喵喵族生成存档，再由开发版读取，检查人物身份、岗位、手动开关、迎新点、床位与睡眠状态。

测试中有意注入一次 `QA_EXPECTED_CALLBACK` 异常，检查扩展回调失败后的提交状态，日志单独保存。启动日志同时独立扫描 XML 错误、引用错误、类型加载错误和运行错误。

### 扩展组合的已有问题

花灵 `FL_Neighbor` 与幽生 `YS_Artisan` 的旧 PawnKind 定义均缺少 `initialResistanceRange`，当前游戏会分别报告一条配置错误。使用原版 0.6.9 的完整扩展组合也出现完全相同的两条错误，证据为 `Validation/run-20261105-234817-3e866f/startup-errors.txt`。

组合回归逐条比对了这两条基线错误，并继续检查新增错误。修复这些旧扩展时，应在对应 PawnKind 配置中补齐合适的抵抗值范围，再完成扩展自己的发布验证。组合测试覆盖加载与同场模板流程，各扩展专属玩法仍需要各自验证。

实验性的 Expressions 模块沿用其独立开发目录。本开发基线采用 0.6.9 正式发布时的模块集合。
